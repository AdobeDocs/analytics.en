# Web SDK migration planner

The Web SDK migration planner helps you plan and execute the migration of your Adobe Analytics tags extension to the Adobe Experience Platform Web SDK. It brings the migration into a single guided workspace within Adobe Experience Platform Data Collection, so you can move from your existing tags implementation to the Web SDK in a structured, trackable way.

>[!AVAILABILITY]
>
>Both the tool and documentation are in active development. Documentation availability is targeted for late September 2026.
